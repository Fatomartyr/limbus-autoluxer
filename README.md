# Limbus Autoluxer

**Автоматический фарм для Limbus Company**

Простая и удобная программа для автоматизации фарма в режиме Luxcavation. Программа сама кликает по кнопкам, завершает бои и запускает следующие проходы.


## Требования

| Компонент | Требование |
|-----------|------------|
| **ОС** | Windows 10 / 11 |
| **Игра** | Limbus Company (оконный режим) |
| **Разрешение** | 1920×1080 (рекомендуется) |
| **Права** | От имени администратора (для работы кликов) |

---

## Установка и запуск

### 1. Распакуйте архив
Распакуйте `LimbusAutoluxer.zip` в любое удобное место (например, на Рабочий стол).

### 2. Запустите игру
Запустите **Limbus Company** в **оконном режиме и перейдите на вкладку Luxcavation**.

### 3. Запустите программу
Откройте папку `LimbusAutoluxer` и запустите файл.
